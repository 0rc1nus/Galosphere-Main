## Allurite block
* Placing an allurite block adjacent to a block that produces sound will mitigate the sounds by 90%
## Burrow Anchor
* Burrow Anchor is a new technical block that acts like a teleporter except the bottom needs to have a sculk linkage to another Anchor
* Once connected, player can sneak on top of the anchor and burrow it like the Warden
![alt](https://i.postimg.cc/j55rr3yn/2025-10-22-20-08-02.png)
## Lumiere Composter
* Right click a semi-filled composter with lumiere shard will turn the compost into lumiere compost, which drops glowstone dust when it's fully filled
## Mole Burrow
* Mole Burrows are a home source for moles and it works similar to beehives
* Collecting it with silk touch drops the entire block with the mole being inside
* Mining Pouches are generated from these blocks. It only increases when a mole digs back into the burrow
* Full Mining Pouches can be returned and it will start spitting gifts like a vault block
## Combustion Table
* A new workstation table that allows the players to customize their own silver bombs. 
* Gunpowder increases the blast radius
* String increases the duration
* Slimeball increases the bounciness of the bomb
## Stranded Membrane Block
* A new variant of cured membrane block that is permeable and transparent
* It can be used to transit items based on its facing direction state
## Shadow Frame
* A new technical decor block that can mimic other blocks based on what you have right clicked it with
* It's collision can be controlled. If it is being powered by redstone, it will be collidable. Otherwise, it will stay non-collidable
* Meaning you can create hidden rooms or traps
